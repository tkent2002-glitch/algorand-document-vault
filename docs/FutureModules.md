# Future Modules

## Status

Deferred

These modules are intentionally not part of the first notarization release.

## Future Module A — Stablecoin Payment Support

Stablecoin support may be considered later for application-level fees.

This does not replace the Algorand network transaction fee, which still requires ALGO.

Deferred concerns:

- USDC / ASA payment handling
- Asset opt-in
- Merchant wallet
- Payment verification
- Refund handling
- Accounting
- Compliance review

## Future Module B — Advanced Privacy / Zero-Knowledge Research

Zero-knowledge proof support may be researched later if the application needs to prove additional statements without exposing sensitive information.

Current privacy model remains:

- Documents stay off-chain
- Metadata stays off-chain
- Only SHA-256 proof payload is prepared for Algorand

## Current Priority

The current product priority remains:

1. Hash document
2. Create proof payload
3. Connect Pera Wallet
4. Sign transaction
5. Submit to Algorand
6. Confirm notarization
7. Verify proof
